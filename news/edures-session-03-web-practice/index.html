Key concepts
  • Nominal: categories with no meaningful order.
  • Ordinal: categories with a meaningful order, but unequal or unknown intervals.
  • Numerical/scale: quantities for which arithmetic calculations are meaningful.
  • Mean: the arithmetic average of a set of scores.
  • Standard deviation: an indication of how spread out scores are around the mean.
